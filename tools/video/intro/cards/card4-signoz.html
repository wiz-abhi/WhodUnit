How it uses SigNoz

All five surfaces, load-bearing — not decorative.

✓
Traces
ONE clickhouse_sql scan via /api/v5/query_range — span predicates, parent_span_id self-join edges, ancestor walks over raw 100%-sampled spans.
✓
Logs
Log features join traces in the same ClickHouse by trace_id, inside that same query. Impossible on Tempo + Loki — separate stores, no join.
✓
Query Builder
The finding compiles to a real builder_trace_operator envelope, and opens in Trace Explorer as a deep link you can edit.
✓
Dashboards
A native Perses v6 panel, authored directly — matching traces over time, share of traffic, and the verification receipt.
✓
Alerts
The discriminator becomes an armed v2alpha1 multi-threshold rule. Webhook delivery proved live: POST “firing” at t+182s.
Plus MCP + Foundry — foundryctl cast -f deploy/casting.yaml: the mandated compliance file is the installer.
