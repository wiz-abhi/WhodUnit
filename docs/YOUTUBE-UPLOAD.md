## Description  (paste everything below the line)

---

Whodunit finds the structural pattern that separates failing traces from healthy
ones — then compiles that finding into a real SigNoz `builder_trace_operator`
query, verifies it against the live engine, and arms it as an alert.

Every tool in this space (Honeycomb BubbleUp, Datadog Trace Patterns, Chronosphere
DDx, Grafana compare) stops at a ranking a human then re-types by hand. Whodunit
closes that loop. There is no LLM anywhere in the runtime — the same input plus
seed always produces the same verdict hash.

Built solo for the Agents of SigNoz hackathon (WeMakeDevs × SigNoz), Track 2 —
Signals & Dashboards.
